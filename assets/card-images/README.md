# Card illustrations

Drop module card pictures here and reference them from `modules.js` via the
optional `image` field (path relative to the site root, e.g.
`assets/card-images/intro-to-cad.png`).

Naming: lowercase module slug + extension. Square (1:1) images are shown
uncropped in the card's media slot; other ratios are center-cropped to square.

Expected slots (added in modules.js, files still missing):

- `intro-to-cad.png` — CAD Level 2 card (white brickbot render)
- `intro-to-vector-design.png` — Intro card (orange 3D-printed box render)
