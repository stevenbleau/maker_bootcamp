# Intro to Sewing — Build Plan

Goal: create a Quarto RevealJS deck for Intro to Sewing using the same layout/theme conventions as other Maker Bootcamp modules.

## Starter checklist

- Replace section divider image at `images/0/0.0.0.png`
- Add step images with naming `{section}.{step}.{image_index}.png`
- Edit `deck.qmd` for slide content
- Adjust layout/colors in `theme/maker-bootcamp.scss` if needed
- Run `quarto preview deck.qmd` while authoring

## Planned sections

1. Overview
2. Tools & Materials — needle, thread, fabric, scissors, pins
3. Threading the Needle
4. Basic Stitches — running stitch, backstitch, whip stitch
5. Your First Project

## Conventions

- Main screenshots / photos should be clear, well-lit, neutral-background shots
- Callout images should show close-up detail of the technique being described
- For hand positions, prefer straight-on or slight angle views
